## Thresholds learned (monitoring)

| Load | Free memory (min) | Python memory (peak) | CPU | Thermal |
|---|---|---|---|---|
| Idle (before runs) | about 2.7 GB (2.1 GB already in swap) | — | — | nominal |
| 1 process, batching benchmark | 1.5 GB | 0.4 GB | 100% | nominal |
| 4 processes, divergence study (7 min) | 0.05 GB | 5.4 GB | 400% | nominal |
| 1 process, determinism gate (11 min) | 0.06 GB | 2.9 GB | 127% | nominal |

"Unused" memory near zero turned out to be normal on macOS (spare memory becomes cache); **swap never grew** in any run, so memory was never truly exhausted. The monitor now records macOS's memory-pressure level (normal throughout since it was added). **Rule: at most 3 parallel brain processes, and stop if memory pressure leaves "normal" or swap grows.** Heat was never above nominal. Background macOS services sometimes push the load average to about 17–20 by themselves.
