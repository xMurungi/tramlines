# Tramlines

*A real fly's brain, copied synapse by synapse, running in a machine that can see its future.*

Tramlines is a whole-brain simulation of the adult fruit fly, *Drosophila melanogaster*, built from the FlyWire connectome. It lives in a small 2D world. Next to it runs a **ghost**: a copy of the same brain, simulated a few seconds ahead, showing where the fly is about to go. Because the simulation is deterministic, the ghost is always right.

Then you press **free will**. One extra spike goes into one neuron, and the future splits into a fan of timelines.

!!! info "Status"
    Phase 1, Hello, brain: the whole brain runs and reproduces the published sugar → MN9 result. See the [journal](journal/2026-10-22-session-2.md) for where things stand, and [owner decisions](owner-decisions.md) for what is waiting.
