# 0010 — Honesty is a feature

- Status: Locked
- Date: 2026-10-22
- Phase: 0
- Decider: Owner

## Context
A fly that "sees its future" invites big claims: uploaded minds, proof of determinism, a conscious fly. None of these is true, and scientists will dismiss the project if it pretends otherwise.

## Options considered
1. **State clearly what the model is and is not**, on a page linked from the main screen, and in The Book.
2. **Let the demo speak for itself.** Cleaner screen, but viewers fill the silence with the boldest reading.

## Decision
The project states plainly what the model is and is not, in [the honesty page](../honesty.md), linked from the viewer.

## Consequences
- Every brain–world mapping is an ADR, so the honesty page can point to it.
- Marketing copy is constrained: no "we uploaded a fly", "this fly is conscious", or "we proved determinism". Bolder framing is Reserved.
- Chapter 26 is an honesty chapter.

## For learners
Being clear about what your work does *not* show is part of doing it well. A simulation that admits its simplifications is more trustworthy, and more interesting, than one that hides them. The honesty page is short; read it before showing anyone the fly.
